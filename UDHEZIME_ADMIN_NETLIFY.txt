SI TA VENDOSNI

1. Ngarkoni të gjithë skedarët e kësaj pakete në repository-n tuaj në GitHub.
   Zëvendësoni skedarët me të njëjtin emër.

2. Hapni https://app.netlify.com dhe hyni me GitHub.

3. Zgjidhni:
   Add new project → Import an existing project → GitHub

4. Zgjidhni repository-n e Klosuja.
   Build command: lëreni bosh
   Publish directory: .

5. Pasi faqja të publikohet, te paneli i Netlify aktivizoni:
   Integrations → Identity → Enable Identity

6. Te Registration zgjidhni:
   Invite only

7. Aktivizoni:
   Services → Git Gateway → Enable Git Gateway

8. Te Identity → Invite users, ftoni email-in tuaj.

9. Hapni email-in e ftesës dhe caktoni fjalëkalimin.

10. Hyni te:
    https://EMRI-I-FAQES.netlify.app/admin.html
    ose
    https://EMRI-I-FAQES.netlify.app/admin

Kur shtypni Publish, Decap CMS krijon automatikisht një ndryshim në GitHub.
Netlify e publikon versionin e ri pas pak çastesh.
