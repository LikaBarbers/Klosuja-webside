# Klosuja – Website me panel administrimi

Website dygjuhësh për ekspozimin e mermerit dhe granitit.

## Paneli i administrimit
Pas lidhjes me Netlify Identity dhe Git Gateway:

- `/admin.html`
- ose `/admin`

Paneli lejon përditësimin e katalogut shqip dhe anglisht, ngarkimin e
fotografive dhe shtimin ose fshehjen e materialeve.

Lexoni `UDHEZIME_ADMIN_NETLIFY.txt` për instalimin.
