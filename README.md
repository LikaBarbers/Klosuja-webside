Nuk ka dosje `assets`: të gjithë skedarët janë në të njëjtin nivel.

## Publikimi me GitHub Pages

1. Ngarkoni të gjithë skedarët në degën `main` të repository-t.
2. Hapni `Settings` → `Pages`.
3. Te `Source` zgjidhni `Deploy from a branch`.
4. Zgjidhni `main` dhe `/(root)`.
5. Shtypni `Save`.

Faqja shqip hapet nga `index.html`; butoni EN hap `index-en.html`.
