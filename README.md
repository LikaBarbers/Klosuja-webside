# Klosuja bilingual demonstration website

This project contains a responsive static website in Albanian and English.

## Pages
- `index.html` – Albanian version
- `index-en.html` – English version
- Use the `AL / EN` control in the navigation to switch language.

## Files
- `styles.css` – shared responsive design
- `script.js` – Albanian interactions
- `script-en.js` – English interactions
- `assets/` – demonstration SVG material illustrations

## Before publishing
Replace the demonstration phone number, email, address, opening hours, material photographs and product details. Connect the contact form to email, WhatsApp or a backend service.
